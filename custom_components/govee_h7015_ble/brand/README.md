# Brand Images

Place the following files here (HA 2026.3+ supports local brand images):

- `icon.png` — 256x256px integration icon
- `logo.png` — wider logo image
- `dark_icon.png` — dark mode variant (optional)
- `dark_logo.png` — dark mode variant (optional)
- `icon@2x.png` — 512x512px retina variant (optional)
- `logo@2x.png` — retina variant (optional)

These images show up in:
- Settings → Devices & Services (integration icon)
- Device page (device logo)
- HACS dashboard

Get the Govee logo from: https://us.govee.com (brand assets)
